  E-commerce product page

![Design preview for the E-commerce product page coding challenge](./design/desktop-preview.jpg)
This is a responsive e-commerce product page built with HTML, CSS, and JavaScript. It displays a product gallery with a lightbox feature, thumbnail image switching, mobile navigation, and an interactive cart and quantity selector. The design is based on a challenge from Frontend Mentor.
📸 Features
✅ Product image gallery with thumbnails

✅ Lightbox (modal) for image viewing on larger screens

✅ Mobile-friendly navigation menu

✅ Quantity selector (increase/decrease)

✅ Add to cart functionality

✅ Responsive layout across devices

🧠 How It Works
Thumbnail click: Changes the main product image and updates the active thumbnail.

Main image click: Opens a lightbox to view images in larger size (only on larger screens).

Lightbox nav: Users can switch between images using "next" and "previous" buttons.

Quantity selector: Allows users to choose how many items to add to the cart.

Add to cart: Displays the number of items added on the cart icon.

Mobile nav: Hamburger menu toggles visibility of mobile navigation links.

📱 Responsive Behavior
Desktop: Full navigation, lightbox on image click.

Tablet/Mobile: Hamburger menu, mobile navigation, inline image slider (no lightbox).
